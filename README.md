# Simple YouTube Filter Combiner
A lightweight Chrome extension that lets you apply multiple YouTube official filters (Upload Date, Duration, Type, Features) together from a single clean panel.  
No API, no layout scraping — fully stable and future-proof.

---

## ⭐ Features
- Combine multiple YouTube official filters at once  
- Upload date, Duration, Type, Features – all in one place  
- Automatically opens YouTube’s filter menu and applies selected options  
- Clean and simple interface  
- No tracking, no API calls, no data collection  
- 100% safe and stable  

---

## 📦 Installation (Manual)
Since the extension is not yet on Chrome Web Store, you can install it manually:

### **1. Download the ZIP**
Click on **Code → Download ZIP**.

### **2. Extract the ZIP**

### **3. Open Chrome Extensions**
Open:

chrome://extensions/

### **4. Enable Developer Mode**
Toggle **Developer Mode** (top-right).

### **5. Load unpacked**
Click **Load unpacked** → select the extracted folder.

The extension will now appear in your Chrome and will load automatically on YouTube.

---

## 🖥 How to Use
1. Open YouTube  
2. Search for anything  
3. A floating panel titled **"Simple YT Filters"** will appear on the right  
4. Choose any combination of:
   - Upload Date  
   - Video Type  
   - Duration  
   - Features (HD, 4K, CC, etc.)  
5. Click **APPLY**  
6. The extension automatically:
   - Opens YouTube’s filter menu  
   - Applies your chosen filters
